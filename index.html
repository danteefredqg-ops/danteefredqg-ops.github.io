Sobre mí

01

Soy Dante Quintero, estudiante de Ingeniería en Sistemas Computacionales, radicado en Monterrey, Nuevo León. Construyo aplicaciones web completas — backend, base de datos y frontend — pensadas para resolver un problema real de negocio, no para lucir complejas.

Me interesa el estoicismo por una razón práctica: separa lo que puedo controlar (mi trabajo, mi disciplina, la calidad del código) de lo que no (el mercado, el cliente, el resultado). Esa distinción es, en el fondo, la misma que uso para depurar un sistema o priorizar un sprint.

Ahora doy el paso hacia el trabajo independiente: quiero construir software para talleres, negocios y equipos que necesitan herramientas simples, seguras y hechas a su medida.

  • I.

    Disciplina

    Código probado antes de entregarlo. Sin atajos que se cobran después.

  • II.

    Claridad

    Cada función, cada pantalla, tiene un propósito que se explica solo.

  • III.

    Utilidad

    Software que resuelve un problema del día a día, no que impresiona y ya.
